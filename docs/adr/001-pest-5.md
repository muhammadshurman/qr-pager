# ADR 001 — Pest 5 instead of Pest 4

- Status: accepted
- Date: 2026-10-25
- Supersedes: `PROJECT_INSTRUCTIONS.md §1` entry "Tests | Pest 4"

## Context
`laravel/laravel ^13.0` (v13.11.0 skeleton, framework v13.38.0) locks
`phpunit/phpunit` at 12.5.40. Verified in-session:
- `pestphp/pest` 4.7.7–4.7.8 declare `conflict: phpunit/phpunit >12.5.33`
- `pestphp/pest` 5.x requires `phpunit/phpunit ^13.x`

Pest 4 is therefore installable only by downgrading PHPUnit to 12.5.33.

## Decision
Lock **Pest 5.3.3 + PHPUnit 13.4.3**. Root `require-dev` pins
`phpunit/phpunit: ^13.4`.

## Consequences
- No backwards pin on a project created the same day.
- Pest 4 syntax/plugins are out of scope; all suites are written against Pest 5.
- `laravel/pao` (MIT, first-party) supports PHPUnit 12–13 and Pest 4–5. Unaffected.
- `PROJECT_INSTRUCTIONS.md §1` must read "Pest 5" and `PLAN.md §1` records this ADR.

## Rejected
Pest 4 + PHPUnit 12.5.33 — day-zero technical debt against the Laravel 13 ecosystem.
